# cartnest.app

The Cartnest 卡带屋 website, served by GitHub Pages at https://cartnest.app (plain static HTML, no build).

## Current download

0.1.0 public test APK is stored in the Cloudflare R2 bucket `cartnest-downloads` under `releases/0.1.0/Cartnest-0.1.0-test.apk`. Both download buttons link to it; `release.json` records the package, size and SHA-256.

The test APK uses package `app.cartnest.test`. Any entered phone number maps to the same dedicated test account and uses code `123456`; no SMS is sent. This is not individual phone account verification.
